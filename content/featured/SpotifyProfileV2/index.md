A complete enterprise-style web reservation system enabling secure user authentication, real-time bus search, ticket booking, booking history, and admin management of users and tickets. Built with a responsive front end and Java-based backend using Servlets, JSP, and MySQL, the system follows MVC architecture and supports scalable reservation workflows.
